# Sprint Calendar & Founder Dashboard 🚀

A high-performance, mobile-optimized Sprint Calendar and Execution Dashboard designed for founders and creators.

## ✨ Features
- **Hourly Daily Schedule**: Plan, edit, and organize each day from wake-up to shutdown with zero guesswork.
- **Dual Accountability Tracking**:
  - `✓ Done` (Good Part): Celebrate completed execution wins.
  - `✕ Missed` (Bad Part): Track slipped or dropped tasks with total honesty.
- **Deliverables Stack**: Accumulates deliverables day-by-day in side-by-side **🟢 Good Part** vs. **🔴 Bad Part** columns with live execution win rates.
- **53-Day Sprint Progress Dashboard**: Real-time trajectory graphs tracking outreach emails, audits, real business conversations, content creation, and habits.
- **Mobile Friendly**:
  - Thumb-friendly 40px+ tap zones.
  - Smooth horizontal swipe navigation for day tabs and section switchers.
  - Floating mobile quickbar to jump directly between schedule and daily scoreboard.
- **Real-Time Cross-Device Sync**: Works across phone and laptop with auto-sync and offline fallback (`localStorage`).
- **Dark / Light Mode**: Seamless theme switching with system auto-detection.

## 🛠️ Local Development
```bash
# Run the local sync server
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
